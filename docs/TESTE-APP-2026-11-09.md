## Tempos

O medidor espera ~0,5 s depois de cada toque, então "pronta" quer dizer em até ~0,5 s.

| O quê | Tempo |
|---|---|
| Toque → tela pronta (todas as telas acima) | até ~0,5 s |
| Cada pedido ao banco | 60 a 300 ms |
| Abrir o app do zero (modo de desenvolvimento) | ~2,1 s antes do 1º pedido ao banco. O pacote de código de desenvolvimento tem 1,8 MB; no app instalado é menor e mais rápido |
| Explorar até os lugares aparecerem | ~0,55 s |
| Cotação do euro no Hoje | ~0,26 s |
| Foto do post (736x736, webp) | link assinado ~0,25 s + download ~0,2 s |
| Capas (Wikimedia, 960 px) | 80 a 130 KB cada, ~0,5 s |
